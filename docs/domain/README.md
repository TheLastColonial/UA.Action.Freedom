# Domain documentation

How the Ukrainian Action domain is described, and where to look.

## The documents

| Document | Read it for |
|---|---|
| [Key concepts](key-concepts.md) | The shared vocabulary: roles, convoy, vehicle, box, manifest, documents, data sensitivity. **Start here.** |
| [Convoy operations](convoy-operations.md) | Planning and running a convoy: vehicles, crew, accommodation, fuel, the manifest sign-off, the Convoy Leader, readiness |
| [Boxes and donations](boxes-and-donations.md) | Boxes, items, donations and donors, Receivers as destinations, reporting |
| [Customs declarations](customs-declarations.md) | The declarations made to customs: GMR, ENS, ELO and the Ukrainian goods list |
| [Decisions](decisions.md) | **Every decision, and why it was made.** Also the open questions and the amendments still due |
| [Ukrainian customs research](ua-customs-requirements.md) | What Ukrainian customs appear to require, with sources and what is unverified. **Research only, not authoritative.** |

The first four describe **business rules** and nothing else. The reasoning, history and open questions live in
[Decisions](decisions.md), and every rule links to the decision it comes from.

## Reading order

1. [Key concepts](key-concepts.md), for the vocabulary.
2. [Convoy operations](convoy-operations.md), for the overall shape.
3. [Boxes and donations](boxes-and-donations.md) and [Customs declarations](customs-declarations.md), for the two
   large areas.
4. [Decisions](decisions.md), when you need to know why a rule is the way it is.
5. [Ukrainian customs research](ua-customs-requirements.md), only when you need the external rules behind a decision.

## Decision IDs

Decisions have stable IDs such as [D3](decisions.md#d3), [P12](decisions.md#p12), [X6](decisions.md#x6) and
[O7](decisions.md#o7). The
letter records where a decision began, not what it governs. See [how to read the decisions](decisions.md#how-to-read-this).
